# Sistema de Reserva de Asientos de Cine

**Estudiante:** Wilmer Xavier López Villacis  
**Asignatura:** Fundamentos de Programacion 

## Objetivo del Programa
El objetivo de este programa es gestionar la reserva de asientos en una sala pequeña de cine de 3 filas por 4 columnas mediante arreglos multidimensionales en Python. El programa permite seleccionar una posición específica (fila y columna) y muestra el estado general de la sala mediante bucles anidados permitiendo realizar la reserva de forma correcta.

## Cómo Ejecutar el Programa
1. Abrir el entorno de programacion de su preferencia
2. Copiar el codigo del repositorio de github y pegarlo en su entorno de programacion
3. Ejecuta el codigo y probar su funcionamiento
